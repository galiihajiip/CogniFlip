Trik Membaca Cabang: Komputer selalu mengeksekusi instruksi dari atas ke bawah secara berurutan. Saat satu kondisi bernilai True, komputer langsung melompat keluar dari seluruh rantai cabang!

navigasi_rambu.py
Python 3.12 
# 1. Nilai sensor yang sedang dideteksi kamera
sensor_warna = "kuning"

# 2. Sistem Evaluasi Percabangan 3-Arah
if sensor_warna == "merah":
    robot.rem_berhenti()       # Pilihan A

elif sensor_warna == "kuning":      ← Cek baris ini!
    robot.pelan_siaga()        # Pilihan B

else:
    robot.tancap_maju()        # Pilihan C

1
Uji Cabang 1: if sensor_warna == "merah" SALAH (False)

Karena "kuning" == "merah" bernilai tidak sama, komputer mengabaikan baris rem_berhenti() dan melompat ke cabang berikutnya.

2
Uji Cabang 2: elif sensor_warna == "kuning" BENAR (True) ⭐

Nilai variabel cocok! Komputer menemukan kecocokan di sini. Apakah ia akan melirik baris else lagi?

🟢 Pilihan C: robot.tancap_maju()

Cabang 'else'

Robot mengabaikan kondisi lampu dan langsung melesat kencang dengan kecepatan penuh melalui tol bebas hambatan.

❓ Pilihan D: Robot Bingung & Menjalankan Keduanya

Error Logika

FlipBot bingung karena ada beberapa kondisi sekaligus dan mengeksekusi instruksi B dan C secara bersamaan.

Dalam arsitektur pemrograman, rangkaian percabangan bertingkat bersifat mutually exclusive (hanya satu pintu yang terbuka). Panduan Berpikir Kognitif

Bayangkan FlipBot sedang membaca daftar resep dari atas:

  • Langkah 1: Lampu merah? Tidak, warna sekarang kuning. Maka lewati rem.
  • Langkah 2: Lampu kuning? Ya, betul! Maka FlipBot mengambil aksi siaga.
  • Langkah 3: Karena sudah menemukan jawaban di Langkah 2, FlipBot TIDAK PERLU melihat opsi berikutnya (else). FlipBot langsung berangkat!

💡 Kata kuncinya: Komputer hemat energi! Begitu ada kecocokan, pencarian langsung berhenti.
