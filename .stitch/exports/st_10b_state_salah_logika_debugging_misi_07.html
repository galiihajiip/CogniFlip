Mengapa Rover Menganggap Jurang Sebagai Lampu Hijau?

Ketika sensor menemukan jurang, variabel sensor_jurang bernilai True (Ada Bahaya). Komputer mengevaluasi:

if True: arrow_forward Jalankan rover.maju()!
Terbalik 180 Derajat

Kamu ingin Rover maju hanya jika TIDAK ADA jurang (if not sensor_jurang:).

Konstruksionisme Kognitif

Komputer tidak tahu apa itu "bahaya" atau "aman". Mesin hanya tahu nilai True atau False. Bandingkan dua diagram jalur di bawah:

cancel Kodemu Sekarang (Tanpa NOT) Bug Terjadi

↓ Tanpa Saklar Pembalik
2. if True: Blok IF Dijalankan
↓ Perintah Salah
3. rover.maju() Bahaya! Terperosok 💥
check_circle Perbaikan Logika (Dengan NOT) Solusi Misi
1. Ada Jurang: sensor_jurang = True
↓ Dibalik oleh Operator 'not'
2. if not True: Menjadi 'if False' (Skip IF!)
↓ Lompat ke Blok ELSE
3. rover.rem_darurat() Aman! Terhenti di Bibir Jurang 🛑
