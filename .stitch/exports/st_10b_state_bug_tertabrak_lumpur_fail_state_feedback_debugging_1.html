Tahukah Kamu? Asal-Usul Istilah "Bug" 🐞

Kata 'Bug' (serangga) pertama kali dipopulerkan oleh Grace Hopper pada tahun 1947, ketika seekor ngengat sungguhan terselip di dalam mesin komputer raksasa Harvard Mark II! Jadi, saat kodemu mengalami bug hari ini, kamu sedang meneruskan tradisi detektif para programmer terhebat di dunia!
