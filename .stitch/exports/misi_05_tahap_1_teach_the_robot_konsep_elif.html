Tapi sirkuit otak robotku bingung: kalau lampu Kuning menyala pelan, apakah itu jalan cadangan atau kondisi kedua? Bagaimana sih cara kerja kata ajaib elif (Else-If) di antara if dan else? Ajari aku dengan bahasamu sendiri ya!”

Evaluasi Alur Bertingkat

Top-to-Bottom

Komputer membaca rambu secara beruntun. Jika kondisi pertama tidak terpenuhi, komputer turun menguji baris berikutnya:

IF
Kondisi 1: Lampu == "Merah"

Jika Benar: Mobil Berhenti total.

arrow_downward Jika Salah (False) lanjut cek...
ELIF
Kondisi 2: Lampu == "Kuning"

Jika Benar: Kurangi kecepatan / Hati-hati.

arrow_downward Jika Masih Salah (False)...
ELSE
Kondisi Sisa: "Hijau"

Jalan terus! Semua syarat lain terlampaui.
