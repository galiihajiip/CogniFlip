Trio Logika: if → elif → else

"Jika Merah berhenti (if), JIKA BUKAN MAKA CEK Kuning pelan-pelan (elif), SELAIN SEMUA ITU Hijau tancap gas (else)!"

Python Lab Preview Terstruktur rapi 
if warna_lampu == "merah":
    robot.berhenti()          # Syarat 1 dicek
elif warna_lampu == "kuning":
    robot.jalan_perlahan()    # Syarat 2 dicek jika syarat 1 salah!
else:
    robot.tancap_gas()        # Pilihan terakhir (Hijau / aman)
